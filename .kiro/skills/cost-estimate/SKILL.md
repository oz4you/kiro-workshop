# コスト見積もり成果物の作成

指定された Step の `terraform/` を読み、月額コスト見積もりを `<step ディレクトリ>/cost-estimate.md` として出力する。

## 手順

1. 対象 Step の `.tf` ファイルを読み、**課金対象リソースを漏れなく列挙**する(無料リソースも「無料」と明記して漏れがないことを示す)
2. 単価は**推測せず AWS Pricing MCP サーバで取得**する(リージョンは ap-northeast-1)。取得できない場合はその旨を明記し、公式料金ページの URL を記載する
3. 従量部分(データ転送、リクエスト数、トークン数等)は前提を置いて計算し、**前提を必ず成果物に明記**する
4. 成果物を作成し、ユーザーに要約(合計月額と支配的なコスト要因 Top3)を報告する

## 成果物フォーマット(cost-estimate.md)

```markdown
# Step N コスト見積もり

- 見積もり日 / リージョン / 為替前提
- 単価の取得方法(Pricing MCP / 料金ページ URL)

## 前提条件
(稼働時間、AZ 数、トラフィック、リクエスト数などの仮定)

## リソース別月額試算
| リソース | 数量 | 単価(根拠) | 月額 |
(無料のものも「$0」で記載)

## シナリオ別合計
| シナリオ | 概算 |
| ハンズオン実施のみ(約2時間) | $X |
| 消し忘れて1ヶ月放置 | $Y |

## コスト削減の選択肢
(構成変更による削減案と、そのトレードオフ)

## 注意
(料金改定の可能性、無料枠の適用条件)
```

## 注意

- 見積もりは意思決定用の概算であり、請求額を保証しない旨を必ず記載する
- 「消し忘れシナリオ」は destroy の動機付けとして必ず含める
- Step 0 の spec 駆動フローと併用する場合、合計月額を requirements.md のコスト上限と突き合わせ、超過していれば警告する
