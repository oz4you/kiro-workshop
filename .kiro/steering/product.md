# Product Overview

このワークスペースは「Kiro CLI × Terraform × AWS 実践ワークショップ」の学習用リポジトリです。

## 目的

受講者が Kiro CLI を活用して、Terraform による AWS インフラの設計・実装・自動化を段階的に習得すること。

## Kiro への期待

- コード生成時は必ず「なぜその構成にしたか」を簡潔に説明する
- 受講者の学習を優先し、いきなり完成コードを出すのではなく、段階的に構築する
- コスト影響のあるリソース(NAT Gateway、ALB、Fargate 等)を作成する場合は、概算コストに言及する
- destroy(クリーンアップ)手順を常に意識させる
